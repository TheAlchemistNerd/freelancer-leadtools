Refactor: Leadtools Containerization and Route Enhancements

This commit introduces operational and functional improvements to the `freelancer-leadtools` service.

# Key Changes
1. **Containerization**:
   - Added a `Dockerfile` to the repository root.
   - This ensures the lead capture and processing service can be orchestrated alongside the rest of the application ecosystem via the centralized `docker-compose.yml`.
   - The container is optimized for production execution with multi-stage builds.

2. **Lead Capture API Updates**:
   - Modified `app/routes/lead_capture.py` to improve payload validation and downstream processing.
   - Enhanced error handling and tracing for incoming lead webhooks.

3. **Documentation**:
   - Updated `README.md` to reflect the new containerized setup instructions and environment variable requirements.

These enhancements ensure Leadtools is robust, portable, and easily deployable in the new unified infrastructure.
